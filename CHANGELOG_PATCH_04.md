# Patch 04 — Полноэкранный выбор категорий и уровней

**Основа**: `main` после merged PR #3 (`03a7d35cd59289ba070a0b870bd4b5a37991a133`).

## Изменения

- **Категории**: отдельный полноэкранный список, а не modal bottom sheet, со стилем Asset Kit и фиксированной нижней навигацией.
- **Уровни**: полноэкранная сетка в 2/3 колонки по доступной ширине; корректная прокрутка, реальные данные API, статусы «Пройден», «В процессе», число букв.
- **Серверный прогресс**: `completed` берётся из `GET /levels`, не рассчитывается по локальному currentLevel; количество уровней также из реального списка.
- **Сохранение попыток**: только при нажатии на уровень, через существующий `startOrResumeAttemptProvider`; повторная попытка проверяется серверным `GET`.
- **Навигация**: главная «Категории» открывает экран категорий; главная «Играть» открывает уровни выбранной категории; «Продолжить» по-прежнему использует прежний метод восстановления.
- **Не тронуто**: backend, migrations, secure guest session, основной UI, игровая клавиатура, существующий old LevelScreen.
- Добавлены unit/widget тесты для прогресса и трёх состояний плитки уровня.

## Технические ограничения

- Нет данных для реальной блокировки уровней; никакого фальшивого lock-state.
- Только последняя активная серверная попытка восстанавливается в домашнем экране, как уже реализовано в текущем `HomeAttemptStore`.
- После открытия уровня доступен прежний **read-only** preview криптограммы. Это ожидаемо до Patch 05 Game UI.
- SDK Flutter недоступен в этой среде. Сборку, линтер и тесты нужно запустить на устройстве пользователя.
