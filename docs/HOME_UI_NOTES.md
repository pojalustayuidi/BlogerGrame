# Prufani Home UI v1

Источники визуального дизайна:
- вложенный пользователем `Prufani_Asset_Kit_v1_1_Full(1).zip`, Asset Kit v1.1;
- `preview/approved_home_reference.png` из этого же архива;
- утверждённый макет с кремовым фоном, фиолетовым hero прогресса, ресурсными карточками, daily/404 и нижней навигацией.

Реализация сохраняет настоящие PNG/SVG и реальные Flutter-виджеты.

## Динамические данные

`economyRepositoryProvider.wallet()` -> `coins`, `lives`, `maxLives`, `hints`, `nextLifeAt`, `lifeRegenMinutes`.

`catalogRepositoryProvider.categories()` + `levels(category: slug)` -> категория, номер следующего незавершённого уровня, процент, пройдено, осталось.

Бонус `+50` из картинки-референса **не вшиваем**: в `LevelSummary` нет размера вознаграждения, и сервер решает его сам.

Уровень `12` и процент `40%` из макета являются только примером, поэтому новый реальный гость увидит реальные значения из БД.

## Навигация сейчас

- Категории: рабочий выбор категории и повторный API-запрос.
- Магазин: серверный каталог в read-only sheet, без расходования монет.
- Профиль: серверный guest ID и копирование ID.
- Настройки: информационный bottom sheet, пока без ложных тумблеров.
- Продолжить: информация о следующем уровне, **без** перехода к старому `LevelScreen`.
- Daily, Case404: planned, честное «скоро».
