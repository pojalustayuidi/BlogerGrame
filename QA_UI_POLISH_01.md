# QA Checklist — выполнять на Samsung S25+ после установки

Автоматические тесты и `flutter analyze` **не могли быть запущены в среде
подготовки патча** — Flutter/Dart SDK отсутствует. Это не отметка PASS.
Ниже команды, тестовые случаи и ожидаемое поведение для локального прогона.

| № | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Первая чистая установка | один гость, далее Home после реальных запросов | проверить |
| 2 | Повторный запуск приложения | прежний UUID, кошелёк и прогресс | проверить |
| 3 | Отключить backend до запуска | ошибка, «Повторить»; после запуска backend восстанавливается | проверить |
| 4 | Кошелёк 5/5 | таймера нет | проверить |
| 5 | Кошелёк 4/5 | отображается дедлайн `nextLifeAt` | проверить |
| 6 | Категория 0 из N | надпись «Играть», не «Продолжить» | проверить |
| 7 | Выбрать уровень, закрыть приложение и открыть | «Продолжить»; точно тот же UUID и серверное поле (просмотр) | проверить |
| 8 | Прокрутить до конца | баннер полностью выше закреплённой нижней навигации | проверить |
| 9 | Открыть и закрыть категории/магазин/профиль | сессия та же, данные не сбрасываются | проверить |
| 10 | Android тема и размер текста 150–200% | не должно быть критических RenderFlex overflow | проверить |

**Подсказка:** при 0 уровнях в базе ни новый гость, ни фальшивые уровни
не появляются; виден пустой каталог. При потерянном/просроченном refresh
не выполняется незаметное создание новой сессии.

Для эмуляции отсутствия сети на ПК останови `npm run dev` (в другом окне),
а затем возобнови и нажми «Повторить». Токены на телефоне не очищай.

## Автоматические проверки на Windows

```powershell
flutter pub get
flutter analyze
flutter test test/backend_models_test.dart test/game_usecases_test.dart test/backend_client_test.dart `
  test/home_overview_test.dart test/startup_bootstrap_test.dart `
  test/home_attempt_store_test.dart test/home_polish_widget_test.dart
```

Существуют старые замечания анализатора в legacy UI. Присылай лог
`flutter analyze`, если появятся **ошибки/новые предупреждения** в новых файлах.
