# UI Polish 01 — изменения

## Экран загрузки

- Заменён существующий `lib/screens/loading_screen/loading_screen.dart` (не создаётся дубль).
- `PrufaniStartupGate` — единая точка входа `main.dart` через существующий ProviderScope.
- Четыре реальные стадии: чтение Secure Storage, `GuestSessionManager.ensureSession`,
  авторизованный запрос профиля, загрузка `homeOverviewProvider`.
- Никаких фиксированных ожиданий и придуманных процентов. Шаги продвигаются
  только после завершённых `Future`.
- Плавный переход `AnimatedSwitcher`, еле заметное движение Пруфика,
  появление логотипа, мерцание искр.
- Маскот с книгой, фон, декор — из `Prufani_Complete_UI_Kit_v1_2`.
- Сетевой сбой: понятный текст, ручное «Повторить», токены не стираются.

## Главное меню

- Убрана лишняя верхняя кнопка магазина; настройки справа сохранены.
- Сокращена шапка, карточки ресурсов с 67 до 56 dp (−16,4%).
- Таймер восстановления показывается только при неполных жизнях.
- Баланс/жизни/подсказки/каталог загружаются через существующие репозитории.
- Карточка уровня короче: название и уровень, категория, один счётчик
  «N из M пройдено», анимированный процент, одна CTA.
- «Играть» если нет известной активной попытки; «Продолжить» только
  при наличии сохранённого UUID и серверной проверки статуса `in_progress`.
- «Загадка дня» и «Дело 404» одного размера, отключены.
- «Больше наград!» компактнее и не пересекается с навигацией.
- Навигация закреплена через `Scaffold.bottomNavigationBar + SafeArea`,
  основное содержимое — независимый прокручиваемый `ListView`.
- Микроанимации: нажатия CTA, прогресс, обновление значений ресурсов;
  секундный таймер перерисовывает только строку ресурсов.

## Данные и безопасность

- Репозитории `auth`, `catalog`, `economy`, `game` прежние, backend не изменён.
- Добавлен `HomeAttemptStore`, который хранит только UUID попытки,
  привязанный к ID гостя, без токенов/ответов/награды.
- При ошибках сети сохранённый UUID не стирается; при серверном 404
  и завершённой попытке — удаляется только устаревший локальный указатель.
- Нет дублирования guest auth; нет обращения к старым `lib/services/api`.
- Не удалены существующие старые игровые экраны/сервисы; их миграция отдельная задача.
